MUHAMMAD QASIM - FRONT-END PORTFOLIO

Files:
- index.html  -> website structure
- style.css   -> website design/style
- script.js   -> JavaScript
- C.V.pdf     -> CV used by the View/Download CV buttons

How to run:
1. Keep all four files in the same folder.
2. Double-click index.html.
3. The portfolio will open in your browser.

For the CV buttons to work, keep C.V.pdf in the same folder.
